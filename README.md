# sql-practice

- T-SQL practice queries on the AdventureWorks2022 sample database, written while working through the DataCamp SQL Server Developer track.

## Setup
- SQL Server Developer edition
- SQL Server Management Studio (SSMS)
- AdventureWorks2022 database (restored from the Microsoft backup file)

## Contents
- `queries.sql`: 15 queries using SELECT, WHERE, JOIN, GROUP BY and HAVING. Each has a one-line comment saying what question it answers.

Started 22 Nov 2026. More queries will be added as I progress through the track.
